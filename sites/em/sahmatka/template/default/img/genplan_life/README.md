# Genplan life — библиотека людей

Виджет грузит `manifest.json` при старте. Если у персонажа указан `sheet.src` и файл открывается — идёт **покадровый walk cycle**. Если файла нет — остаётся векторный SVG.

## Текущий статус

По умолчанию `manifest.json` сейчас пустой (`src: ""`) — виджет работает на стабильном векторном fallback.
Когда будете готовы подключать каталог, достаточно заполнить `src` у нужных персонажей.

Пересборка шита после правок спрайтов:

```
node sites/em/sahmatka/template/default/img/genplan_life/export_people_sheets.js
```

## Как подставить свой PNG/WebP

Положите файл сюда и пропишите в манифесте:

```json
"person_w1": {
  "sheet": {
    "src": "person_w1_walk.webp",
    "frames": 8,
    "cols": 8
  }
}
```

Требования к кадрам:

- горизонтальная полоса, кадры одинаковой ширины
- прозрачный фон, ноги на одной линии (низ кадра = земля)
- 8 кадров = полный цикл (2 шага)
- высота 64–96 px для фото/3D; для SVG-шита достаточно 28 px
