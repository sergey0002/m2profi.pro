# Задача 3 (EM): Форма «Добавить запись» на странице zapiskeys

**Дата:** 06.07.2026  
**Область:** `sites/em/sahmatka/` (только EM, sigma не трогаем)  
**Страница:** [ctrind.php?ctr=zapiskeys](https://em.m2profi.pro/sahmatka/ctrind.php?ctr=zapiskeys) (Запись на выдачу)  
**План реализации:** [plan.md](./plan.md)  
**Связанные документы:** [ctr_legacy.md](../../ctr_legacy.md)

---

## 1. Цель

Дать администратору (и пользователю `op15`) возможность **создавать запись на выдачу ключей** из бэкенд-списка, в **модальном окне (iframe)**, по тому же паттерну, что редактирование записи (`act=edit`).

Форма должна поддерживать два режима выбора даты/времени:

1. **По графику** — только доступные слоты из `keys_graficx`, с отображением занятости `(свободно/всего)`.
2. **Вне графика** — все дни на месяц вперёд и полная сетка времени, независимо от занятости.

| Поле | Тип |

| Телефон | text |
| E-mail | text |

| Тип договора | select: ДДУ / ДКП |

---

## 3. Текущий статус в репозитории

- Кнопка и `act=backendform` **заготовлены**, но скрыты и **не реализованы**.
- Прототип формы есть в `ctr__zapisx::act__bedit`, сохранение **сломано** (неверный контроллер в action).
- На production видна ссылка «Добавить запись» — в git кнопка `display:none`.
- Подробный аудит и пошаговый план — в [plan.md](./plan.md).

---

## 4. Критерии приёмки (кратко)

- Видимая кнопка «Добавить запись» → модалка с формой.
- Оба режима графика работают согласно ТЗ в плане §1.3–1.4.
- Запись сохраняется в `zapis`, отображается в таблице списка.
- Права: только admin / op15.
- Публичная запись и редактор графика не регрессируют.
