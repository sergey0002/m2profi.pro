# Решения заказчика (задача 12)

**Дата фиксации:** 11.08.2026  
**Спека:** [plan.md](./plan.md)

---

## Продукт

| # | Тема | Решение |
|---|------|---------|
| Q1 | Графика | **Встроенные SVG** в виджете/редакторе; заказчик файлы не поставляет |
| Q2 | Облака | Да, медленный drift; **не дым** |
| Q3 | Птицы | Random спавн/дуги, **без** обязательного трека |
| Q4 | Машины / люди / собаки | Трек + скорость + период + выбор спрайта (2–3 варианта) |
| Q5 | Разметка | Новый режим редактора рядом с Полигоны/Подписи: **Жизнь** |
| Q6 | Навигация | Life-слой **не перехватывает** клики/тапы по домам |
| Q7 | Ветка | Отдельная `feature/12-genplan-life` от `master` |
| Q8 | reduced-motion | При `prefers-reduced-motion: reduce` — слой выключен |

---

## Модель (закрыто в плане)

| Тема | Решение |
|------|---------|
| Трек vs агент | **Раздельно:** трек = polyline + роль; агент = species + speed + period + sprite + `track_id` |
| Один трек — много агентов | Да (несколько машин на одной дороге) |
| Птицы / облака | Агенты без `track_id` (или `track_id IS NULL`) |
| Полигоны домов | Таблица `genplan_polygons` **не меняем** |

Открытых вопросов нет — детали в [plan.md](./plan.md).
