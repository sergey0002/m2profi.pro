# Решения заказчика (задача 12)

**Дата фиксации:** 11.08.2026 (уточнено тем же днём)  
**Спека:** [plan.md](./plan.md)

---

## Продукт

| # | Тема | Решение |
|---|------|---------|
| Q1 | Графика | **Встроенные SVG** в виджете/редакторе; заказчик файлы не поставляет |
| Q2 | Облака | Да, медленный drift; **не дым** |
| Q3 | Птицы | Random **по диагонали** экрана/карты; **отключаемые** |
| Q4 | Машины / люди | **Спец-инструменты** «Машина» / «Человек»: рисуют линию **как полигон** (клики по вершинам), но **без замыкания** |
| Q5 | Собаки | Опционально Stage 2; тот же open-polyline паттерн |
| Q6 | Разметка | Режим **Жизнь** рядом с Полигоны/Подписи |
| Q7 | Навигация | Life-слой **не перехватывает** клики/тапы по домам |
| Q8 | Ветка | `feature/12-genplan-life` от `master` |
| Q9 | reduced-motion | `prefers-reduced-motion: reduce` → весь life off |
| Q10 | Mount API | Из `GenplanWidget.mount` можно **отключить** по отдельности: cars / people / birds / clouds (и life целиком) |
| Q11 | Свет | Лёгкий **ambient light overlay** (день/вечер/пульс), не мешает навигации; см. plan §6 |

---

## Модель (закрыто в плане)

| Тема | Решение |
|------|---------|
| Рисование пути | Leaflet.Draw **polyline** (open); UX «как полигон», finish без замыкания |
| Инструмент Машина | Создаёт track `role=road` (+ опц. дефолтный car-agent) |
| Инструмент Человек | Создаёт track `role=walk` (+ опц. дефолтный person-agent) |
| `closed` | Для car/person **всегда 0** в Stage 1 (петли — backlog) |
| Птицы / облака | Без трека; конфиг в БД и/или только mount-флаги |
| Полигоны домов | `genplan_polygons` **не меняем** |

Открытых вопросов нет — детали в [plan.md](./plan.md).
