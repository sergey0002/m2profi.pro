# Task #3 — Лента изменений файлов (doc)

Краткое ТЗ. Ветка: `feature/3-doc-file-audit` (от `feature/2-doc-modals`).

Полный текст (gitignored): `sites/doc/.doc/tasks/3/doc.md`, as-is: `sites/doc/.doc/tasks/3/as-is.md`.

## Цель

Общая **лента аудита** всех действий с файлами и папками (включая скачивание и просмотр) + **откат** любого откатываемого действия администратором, с возможностью откатить откат. Откат = новое событие в ленте со ссылкой на исходное.

## Сейчас (кратко)

- «История» в карточке — заглушка, не журнал.
- Версий бинарников нет: save обновляет одну строку `files2node`.
- Download / view / move / rename **не** пишутся в общий лог.

## MUST

1. Страница ленты + пункт меню **«Изменения»**.
2. Фильтры: пользователь, даты, тип действия.
3. Строка = одно действие; тип цветом; ссылка на файл.
4. Фиксация: create, replace, edit, delete/restore, move, rename, dir-операции, **download**, **view**.
5. Кнопка отката только у администратора; download/view не откатываются.
6. Откат инвертирует состояние теми же операциями; пишет rollback-событие; откат отката разрешён.

## Не трогать без нужды

`myfw_iframe.js`, общий `upload.php` / `filed.php` (как в #2). Аудит — в doc act_* и writer после успеха.

## Статус

ТЗ принято в ветку; реализация — после детального плана stage 0/1.
